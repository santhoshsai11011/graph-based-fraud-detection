# Graph-Based Fraud Detection System

## Overview

A graph-based fraud detection system built on the Elliptic Bitcoin Dataset.

The project compares:
- Rule-Based Detection
- Logistic Regression
- XGBoost
- GraphSAGE

and provides node-level fraud prediction with interactive graph visualization.

## Dataset

- 203,769 transactions
- 234,355 transaction relationships
